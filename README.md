# Ezechime Énuani Dictionary

**The Language of Aniocha North, Delta State, Nigeria.**

A mobile-first progressive web app foundation for documenting the Ezechime community variety of Énuani.

## Current build
- Search Énuani words and English meanings.
- Filter entries by category.
- Responsive mobile layout.
- PWA manifest and service worker for installability/offline shell.
- Seed entries come from vocabulary directly supplied or confirmed by the community contributor. Preserve tone marks and spelling exactly.

## Important next steps
This is the public dictionary foundation, not the finished publishing system. Secure private administration, cloud database, audio recording/upload, and live publishing require Firebase project configuration, authentication, Firestore rules, and Storage rules. Never put service account credentials or private keys in this repository.

## Deploy
Import this GitHub repository into Vercel and deploy from the `main` branch. Static site, no build command; output directory is repository root.
